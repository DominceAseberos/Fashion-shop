# Fashion Storefront

## What is this?
This is a personal project built for practicing storytelling website development. It focuses on creating an immersive, editorial-style fashion storefront with smooth scrollytelling and high-end visual pacing.

## Design System & Tech Stack
The design system emphasizes "quiet luxury," utilizing premium typography, carefully paced layouts, and high-quality imagery to create a bespoke brand identity.

- **Core**: React, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Animations**: GSAP (GreenSock Animation Platform) for seamless scroll interactions and visual storytelling.
